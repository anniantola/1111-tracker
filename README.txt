11:11 & 22:22 Tracker v6 — privacy-clean PWA

This public app contains no historical sighting data. New installs start with 11:11 and 22:22 trackers and an empty log.

Use Settings > Data > Import to restore a private v5 or v6 JSON backup locally on the device. Import supports Merge and Replace. Data is stored in browser/PWA local storage and is not uploaded to GitHub.
